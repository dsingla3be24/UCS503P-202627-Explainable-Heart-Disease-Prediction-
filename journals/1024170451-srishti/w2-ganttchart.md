# 🚀 Week 2: Project Scheduling & Gantt Chart

**📅 Date:** August 21 – August 27, 2026  
**🎯 Core Task:** Designed the comprehensive Gantt chart outlining the project timeline, milestones, and task dependencies for the development of Cardio AI.

---

### 🛠️ Key Contributions & Decisions

* **Task Identification:** Defined the primary phases and tasks required for the project lifecycle:
  * **Requirements & Design:** Initial proposal, system architecture, and UML diagrams.
  * **Model Development:** Data preprocessing, training the CNN-LSTM-Attention model, and integrating XAI (Grad-CAM, SHAP).
  * **System Integration:** Developing the Flask REST API and setting up the MySQL database.
  * **Frontend & Visualization:** Building the web interface and interactive Plotly.js dashboards for explainability.
* **Timeline Mapping:** Mapped out the weekly schedule, allocating appropriate timeframes for research, coding, testing, and documentation to ensure timely completion.
* **Dependency Tracking:** Structured task dependencies to highlight critical paths. For example, model training must precede API integration, and API completion is required before frontend XAI dashboards can be finalized.
* **Diagram Generation:** Produced the final Gantt chart to be included in the official project documentation to guide the development workflow.
