Stakeholder (indirect)

👤 Clinician (Primary Actor)

  • Enters 14 clinical biomarkers via web form (age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal)
  • Triggers real-time heart disease risk prediction
  • Reviews Grad-CAM / Attention / SHAP explanations on Plotly.js charts
  • Downloads auto-generated PDF diagnostic report
  • Searches patient history by name or hospital ID
  • Runs EDA, holdout training, 5-fold cross-validation via CLI
  • Launches ablation study (CNN vs CNN-LSTM vs CNN-LSTM-Attn)
  • Runs Keras Tuner hyperparameter optimisation

👤 Patient (Stakeholder)

  • Indirect actor — receives PDF diagnostic report from clinician
  • Longitudinal records stored in MySQL for follow-up visits
  • Demographic auto-aging for returning patients (age computed from last visit)

⚙️ ML Engine (Supporting)

  • Runs CNN-LSTM-Attention inference (TF Keras or pure NumPy engine)
  • Executes preprocess_pipeline(): median imputation, ClinicalRangeScaler, one-hot encoding, GASF polar transform
  • Applies SMOTE oversampling on training set only
  • Computes Grad-CAM via GradientTape logit differentiation
  • Computes SHAP via KernelExplainer with k-means background
  • Extracts attention alphas from TabularAttention layer
  • Calculates Spearman + Jaccard XAI agreement metrics

🗄️ MySQL Database (Supporting)

  • Tables: patients (hospital_patient_id, name), clinical_records (14 features, recorded_at), ai_diagnoses (probability, class, primary_drivers, pdf_path)
  • get_or_create_patient(): deduplication by hospital ID
  • insert_patient_record(): stores features + AI diagnosis + top 3 drivers
  • search_patient_history(): LIKE name / exact ID, grouped by patient
