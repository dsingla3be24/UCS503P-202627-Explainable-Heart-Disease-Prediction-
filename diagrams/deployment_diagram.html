TIER 1 Clinician Client Workstation

Hosts the presentation environment executed inside standard modern browsers.

  • CardioAI Web UI: Form validation, multi-tab telemetry, responsive glassmorphism.
  • PyVis Visualizer: Force-directed interactive explainability graph rendering.
  • PDF.js Viewer: Immediate clinical dossier preview and download.
  • Artifacts: index.html, client_logic.js, style.css.

TIER 2 CardioAI Application Server

Orchestrates machine learning pipelines, feature transformation, and API dispatching.

  • Flask Web API: Validates incoming 13-feature JSON payloads, assigns session IDs.
  • GAF Engine: Converts 1D tabular sequences into 2D polar correlation images.
  • CNN-LSTM-Attention: Deep spatial-temporal inference with biomarker attention.
  • XAI Engine: Generates Grad-CAM heatmaps and SHAP feature attributions.
  • Artifacts: app.py, main.py, model_best_weights.h5, heart_disease_cleveland.csv, clinical_guidelines.json.

TIER 3 MySQL Database Storage

Isolated relational storage executed inside Docker container cardio_ai_db.

  • Patients Registry: Hospital patient identifiers, names, timestamps.
  • Clinical Records: 13 raw biomarkers (trestbps, chol, fbs, thalach, oldpeak, ca, thal).
  • AI Diagnoses: Confidence probabilities, risk class, top drivers, PDF paths.
  • Artifacts: init.sql DDL initialization, mysql_data persistent volume.

TIER 4 Container Admin & Networking

Containerized administrative toolset and multi-tier network topologies.

  • phpMyAdmin Container: Direct SQL management GUI on Port 8080:80.
  • Port Forwarding: MySQL external 3307 → internal 3306; Flask WSGI 5000:5000.
  • Docker Compose: Orchestrates service dependencies, health checks, bridge networks.
  • Artifact: docker-compose.yml.
