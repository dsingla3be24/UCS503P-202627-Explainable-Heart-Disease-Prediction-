Introduction & Motivation

🫀 The Healthcare Challenge

  • Cardiovascular disease is the leading cause of death globally — 17.9 million deaths per year (WHO)
  • Early detection can significantly reduce mortality rates
  • Traditional diagnosis requires expensive imaging, invasive procedures, and expert cardiologists
  • Machine Learning & Deep Learning can assist in heart disease risk prediction

⚠️ The Black-Box Problem

  • Complex AI models can behave like black boxes
  • A prediction alone does not explain why a patient was classified as high or low risk
  • Without transparency, clinicians cannot trust or adopt AI-assisted tools
  • Explainable AI (XAI) can make model predictions easier to understand

Problem Statement

Existing heart disease prediction approaches may suffer from several key limitations:

🔒

Black-Box Predictions

Models output a risk score without any explanation of how the decision was made

🔍

Limited Interpretability

Difficult to understand which clinical features influenced an individual prediction

📊

No Visual Reasoning

Limited visualization of model reasoning and feature-level contributions

🧩

Individual Prediction Gap

Difficult to explain why a specific patient was classified as high or low risk — global metrics alone are insufficient

⚙️

Disconnected Systems

Prediction systems and explainability tools are often developed separately, lacking an integrated framework

Research Question: "How can we design a heart disease prediction system that combines deep learning with multiple explainability techniques to provide both a prediction and understandable reasoning behind that prediction?"

Deep Learning Approaches

  • Attention-based models

Higher capacity but often function as black boxes

Explainable AI Methods

  • SHAP — Shapley value-based feature attribution
  • LIME — Local interpretable approximations
  • Grad-CAM — Gradient-based visual explanations
  • Attention Weights — Model-internal focus indicators
Proposed Research Gap

This project proposes to explore a unified system combining:

  • CNN-LSTM-Attention architecture
  • GAF representation of tabular clinical data
  • Multiple XAI techniques in a single framework
  • Integrated explainable visualization

The novelty and specific gap will be further validated through a comprehensive literature review.

Project Objectives

1

Design a heart disease risk prediction system using deep learning that takes clinical patient parameters as input and outputs a heart disease risk assessment.

2

Preprocess and transform clinical patient data using appropriate encoding, scaling, class balancing, and explore Gramian Angular Field (GAF) transformation for 2D representation.

3

Explore a CNN-LSTM-Attention architecture that combines spatial feature extraction (CNN), sequential relationship modeling (LSTM), and learnable feature emphasis (Attention).

4

Integrate multiple XAI techniques — Attention, Grad-CAM, SHAP, and LIME — to provide complementary explanations for each individual prediction.

5

Provide understandable explanations for individual predictions by mapping AI-driven feature importance to clinically meaningful interpretations.

6

Develop a modular software application with a web-based interface for prediction input, explainability visualization, and report generation.

All objectives are described in future/planned tense — this is a proposed project.

Gramian Angular Field (GAF) Transformation

Why Consider GAF?

  • Original clinical data is tabular (1D)
  • CNNs are designed for spatial pattern recognition
  • GAF can transform a 1D feature vector into a 2D matrix representation
  • The resulting 2D matrix encodes pairwise feature relationships
  • This representation can be explored using CNN-based feature extraction

Transformation Steps

Step 1: Scale each feature to [−1, 1] range

Step 2: Compute angular representation: φ = arccos(x̃)

Step 3: Construct GASF matrix: GASF[i,j] = cos(φᵢ + φⱼ)

Multi-Technique XAI Framework

Proposed Explainability Approach
🎯

Attention Weights

Will show which learned representations receive greater attention from the model. Provides a model-internal perspective on feature importance.

Intrinsic to the architecture — no external computation needed

🔥

Grad-CAM

Will provide a visual heatmap of influential regions in the CNN feature maps. Uses gradients to identify which spatial areas activate the prediction.

Gradient-based — requires access to model internals

🧮

SHAP

Will estimate each feature's marginal contribution toward an individual prediction using Shapley values from cooperative game theory.

Model-agnostic — provides mathematically grounded attributions

🔍

LIME

Will provide a local interpretable approximation around an individual prediction by fitting a simple model on perturbed neighborhood samples.

Model-agnostic — perturbation-based local explanations

One Prediction → Four Explanation Perspectives
The project will investigate whether the methods provide complementary or consistent explanations for individual patients.

✅ Validation Strategy

  • Hold-out testing — 70/10/20 stratified split
  • Stratified K-Fold cross-validation — for robustness
  • Ablation study — CNN vs CNN-LSTM vs CNN-LSTM-Attention
  • SMOTE applied inside each fold to prevent data leakage

🔍 XAI Evaluation

  • Feature ranking comparison across XAI methods
  • Top-K feature overlap (Jaccard Similarity)
  • Rank correlation (Spearman) between methods
  • Consistency check — do methods agree on important features?
  • Comparison with established medical literature

🧪 Software Testing

  • Unit testing — preprocessing, GAF, model functions
  • Integration testing — end-to-end API pipeline
  • Input validation — handling invalid/missing inputs
  • Edge-case testing — out-of-distribution values
  • UI testing — form validation, result display

Future Scope & Current Limitations

🚀 Future Scope

📂 Larger & diverse datasets — Framingham, MIMIC-III, Kaggle Heart Failure

🌍 External dataset validation — test generalization on unseen populations

🔬 Additional XAI methods — Integrated Gradients, Counterfactual Explanations

🤖 Advanced architectures — Vision Transformers, Graph Neural Networks

📱 Mobile deployment — cross-platform app for clinical use

📈 Longitudinal analysis — track patient risk progression over time

🔒 Privacy-preserving learning — federated learning across hospitals

⚠️ Current Scope & Limitations

Dataset Size

Initial development will use a public dataset (~303 records). Dataset size may limit generalization to broader populations.

XAI Interpretation

XAI explanations require careful interpretation. Feature importance does not always imply direct causation.

Not a Medical Device

The system is intended as a research/educational prototype, not an autonomous medical diagnosis system. Clinical validation would be required for real deployment.

Single Dataset

Conclusions will be specific to the Cleveland dataset. Multi-dataset validation is planned as future work.
